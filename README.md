# Deep Learning CIA (2087101): Backpropagation and Optimizers

## Contents
- `Deep_Learning_Backprop_Optimizer_Comparison.ipynb`: documented notebook for both questions, code, equations and interpretation.
- `outputs/experiment_output.txt`: output logs from a local run if available.
- `outputs/optimizer_convergence.png` and `outputs/numpy_backprop_loss.png`: generated loss curves.
- `REPORT.md`: short report.
- `requirements.txt`: dependencies.

## Run
1. Install Python 3.10+.
2. Run `pip install -r requirements.txt`.
3. Open the notebook in Jupyter and run all cells from top to bottom.
